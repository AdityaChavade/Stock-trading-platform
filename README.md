# Herodha

A trading dashboard built with **React, Node.js, Express, and MongoDB**.

### Features

* User Authentication
* Trading Dashboard
* Holdings & Positions
* Orders & Funds
* Live Bitcoin Price
* Interactive Charts

### Tech Stack

React.js • Node.js • Express.js • MongoDB • JWT • Chart.js

### Run

```bash
npm install
npm run dev
```
